1. Distributed Tracing дегеніміз не?

Бір пайдаланушы сұрауы бірнеше микросервистен өтеді. Әр сервистің журналы бөлек, сондықтан «уақыт қай жерде жоғалды?» деген сұраққа журналдар жауап бере алмайды. Таратылған трассировка бір сұраныстың барлық сервис арқылы өткен жолын бір суретке жинайды.

2. Trace және span

Trace

Бір сұраныстың толық жолы. Барлық бөлігі бір trace_id-ге (32 hex таңба) ие.

Span

Бір операция: атауы, басталуы, ұзақтығы, атрибуттары, статусы (OK / ERROR).

parent_id

Ата-ана span. Түбірдің parent_id-і бос, қалғандары ағаш құрайды.

Span түрі

server — сұрау қабылдау, client — басқа сервисті шақыру, internal — ішкі жұмыс (ДҚ, кэш).

3. Контексті беру: traceparent

Келесі сервис сол трассаның жалғасы екенін білуі үшін әр шығатын сұрауға W3C Trace Context тақырыбы қосылады (inject), ал қабылдаушы оны оқиды (extract).

traceparent: 00-4bf92f3577b34da6a3ce929d0e0e4736-00f067aa0ba902b7-01
             │  └ trace_id (32)                    └ span_id (16)    └ 01 — жазылады
             └ нұсқа
with tracer.span("HTTP GET grades", kind="client"):
    req = urllib.request.Request(url, headers=inject({}))   # traceparent қосылды

4. Сарқырама (waterfall)

Трасса уақыт осінде «сарқырама» болып көрсетіледі: әр жол — бір span, ені — ұзақтығы, шегініс — кімнің баласы. Ең ұзақ жапырақ span (баласы жоқ) — әдетте баяулаудың нақты себебі.

6. Sampling

Әр сұрауды жазу қымбат. Head-based sampling шешімді трассаның басында қабылдайды (мысалы, 20%) және ол traceparent флагымен (01 / 00) барлық сервиске беріледі — трасса не толық жазылады, не мүлдем жазылмайды. Кемшілігі: сирек қатені өткізіп алуы мүмкін. Tail-based sampling трасса аяқталғаннан кейін шешеді: қатесі бар немесе баяу трассаларды әрқашан сақтайды.

Span атрибуттарына құпиясөз, токен, жеке деректер жазылмайды: трассаларды көп адам көреді.

1-тапсырма. Трассировка агенті: trace, span, traceparent (10 мин, 25 ұпай)

Трасса (trace) — бір сұраныстың толық жолы; span — сол жолдағы бір операция (уақыты, атауы, атрибуттары, қатесі). Барлық span-дар бір trace_id-мен байланысады, ал әр span өзінің ата-анасын (parent_id) біледі. Сервистер арасында контекст W3C traceparent тақырыбымен беріледі.

Файл: tracer.py

# tracer.py — оқу трассировка агенті (OpenTelemetry / Jaeger идеясы бойынша)
# Агентті баптау — орта айнымалылары арқылы:
#   TRACE_SAMPLE_RATE=1.0                           сұраулардың қанша үлесі жазылады (0..1)
#   TRACE_FILE=traces/spans.jsonl                   жергілікті жинағыш (collector) файлы
#   OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4318   Jaeger-ге жіберу (міндетті емес)
import json
import os
import random
import threading
import time
import urllib.request
from contextlib import contextmanager

SAMPLE_RATE = float(os.environ.get("TRACE_SAMPLE_RATE", "1.0"))
TRACE_FILE = os.environ.get("TRACE_FILE", "traces/spans.jsonl")
OTLP = os.environ.get("OTEL_EXPORTER_OTLP_ENDPOINT", "")
LOCK = threading.Lock()
CURRENT = threading.local()                 # әр ағынның (сұраудың) ағымдағы span-ы
KINDS = {"internal": 1, "server": 2, "client": 3}


def new_id(n_bytes):
    return "%0*x" % (n_bytes * 2, random.getrandbits(n_bytes * 8))


class Span:
    def __init__(self, service, name, kind, trace_id, parent_id, sampled):
        self.service, self.name, self.kind = service, name, kind
        self.trace_id, self.parent_id, self.sampled = trace_id, parent_id, sampled
        self.span_id = new_id(8)
        self.attrs, self.status = {}, "OK"
        self.start = time.time_ns()

    def set(self, key, value):
        self.attrs[key] = value

    def error(self, message):
        self.status = "ERROR"
        self.attrs["error.message"] = message

    def traceparent(self):
        """W3C Trace Context: 00-<trace_id 32>-<span_id 16>-<флаг: 01 жазылады, 00 жоқ>"""
        return "00-%s-%s-%s" % (self.trace_id, self.span_id, "01" if self.sampled else "00")


def extract(headers):
    """Келген сұраудың traceparent тақырыбынан контекстті алу."""
    try:
        version, trace_id, span_id, flags = headers.get("traceparent", "").split("-")
        if len(trace_id) == 32 and len(span_id) == 16:
            return trace_id, span_id, flags == "01"
    except ValueError:
        pass
    return None


def inject(headers):
    """Шығатын сұрауға ағымдағы контекстті қосу."""
    span = getattr(CURRENT, "span", None)
    if span:
        headers["traceparent"] = span.traceparent()
    return headers


class Tracer:
    def __init__(self, service):
        self.service = service

    @contextmanager
    def span(self, name, kind="internal", headers=None):
        parent = getattr(CURRENT, "span", None)
        ctx = extract(headers) if headers is not None else None
        if parent:                                   # осы сервистің ішіндегі бала span
            trace_id, parent_id, sampled = parent.trace_id, parent.span_id, parent.sampled
        elif ctx:                                    # басқа сервистен келген сұрау
            trace_id, parent_id, sampled = ctx
        else:                                        # жаңа трасса (түбір span)
            trace_id, parent_id, sampled = new_id(16), "", random.random() < SAMPLE_RATE
        s = Span(self.service, name, kind, trace_id, parent_id, sampled)
        CURRENT.span = s
        try:
            yield s
        except Exception as e:
            s.error(repr(e))
            raise
        finally:
            s.end = time.time_ns()
            CURRENT.span = parent
            if s.sampled:
                export(s)


def export(s):
    rec = {"trace_id": s.trace_id, "span_id": s.span_id, "parent_id": s.parent_id, "service": s.service,
           "name": s.name, "kind": s.kind, "start_us": s.start // 1000,
           "duration_ms": round((s.end - s.start) / 1e6, 1), "status": s.status, "attrs": s.attrs}
    with LOCK:
        os.makedirs(os.path.dirname(TRACE_FILE) or ".", exist_ok=True)
        with open(TRACE_FILE, "a", encoding="utf-8") as f:
            f.write(json.dumps(rec, ensure_ascii=False) + "\n")
    if OTLP:
        threading.Thread(target=send_otlp, args=(s,), daemon=True).start()


def send_otlp(s):
    """Span-ды Jaeger-ге OTLP/HTTP (JSON) форматында жіберу: POST /v1/traces"""
    attrs = [{"key": k, "value": {"stringValue": str(v)}} for k, v in s.attrs.items()]
    span = {"traceId": s.trace_id, "spanId": s.span_id, "parentSpanId": s.parent_id, "name": s.name,
            "kind": KINDS[s.kind], "startTimeUnixNano": str(s.start), "endTimeUnixNano": str(s.end),
            "attributes": attrs, "status": {"code": 2 if s.status == "ERROR" else 1}}
    body = {"resourceSpans": [{
        "resource": {"attributes": [{"key": "service.name", "value": {"stringValue": s.service}}]},
        "scopeSpans": [{"scope": {"name": "aec-tracer"}, "spans": [span]}]}]}
    req = urllib.request.Request(OTLP.rstrip("/") + "/v1/traces", data=json.dumps(body).encode("utf-8"),
                                 headers={"Content-Type": "application/json"})
    try:
        urllib.request.urlopen(req, timeout=3).read()
    except OSError as e:
        print("[tracer] Jaeger-ге жіберілмеді:", e)


if __name__ == "__main__":                       # агентті тексеру
    t = Tracer("demo")
    with t.span("сыртқы операция") as a:
        with t.span("ішкі операция 1"):
            time.sleep(0.05)
        with t.span("ішкі операция 2") as b:
            b.set("db.table", "students")
            time.sleep(0.02)
    print("trace_id:", a.trace_id)
    print("traceparent:", a.traceparent())
    print("3 span жазылды ->", TRACE_FILE)
  1. tracer.py файлын жасап, тексеріңіз: python3 tracer.py → trace_id, traceparent және «3 span жазылды -> traces/spans.jsonl».
  2. traces/spans.jsonl файлын ашыңыз: үш жолдың trace_id-і бірдей ме? Қай span түбір (parent_id бос)? Ішкі span-дардың parent_id-і нені көрсетеді?
  3. traceparent мәнін бөліктерге бөліп түсіндіріңіз: 00 — нұсқа, 32 таңба — trace_id, 16 таңба — span_id, 01 — жазылады (sampled).
  4. Кодты түсіндіріңіз: CURRENT (threading.local) не сақтайды? span() үш жағдайды (бала span, басқа сервистен келген, жаңа трасса) қалай ажыратады? inject() мен extract() не істейді?

Есепке: tracer.py, spans.jsonl мазмұны, traceparent талдауы, сұрақтарға жауап.

# services.py — трассировкасы бар 4 микросервис: gateway -> report -> students, grades
import json
import random
import threading
import time
import urllib.error
import urllib.request
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from urllib.parse import parse_qs, urlsplit

from tracer import Tracer, inject

PORTS = {"gateway": 8200, "report": 8201, "students": 8202, "grades": 8203}
STUDENTS = {1: "Айгерім Сапарова", 2: "Нұрлан Әлібек", 3: "Дәулет Қасымов", 4: "Аружан Сейітова"}
GRADES = {1: ["A", "B+"], 2: ["B", "B"], 3: ["C+", "A-"], 4: ["A", "A"]}
ARCHIVE = {3}                         # бұл студенттің бағалары ескі мұрағатта сақталған


def call(tracer, service, path):
    """Басқа сервиске HTTP сұрау: client span + traceparent тақырыбы."""
    with tracer.span("HTTP GET " + service, kind="client") as s:
        url = "http://127.0.0.1:%d%s" % (PORTS[service], path)
        req = urllib.request.Request(url, headers=inject({}))
        s.set("http.url", url)
        try:
            r = urllib.request.urlopen(req, timeout=5)
        except urllib.error.HTTPError as e:
            r = e
        s.set("http.status_code", r.status)
        data = json.loads(r.read())
        if r.status >= 400:
            s.error("%s жауабы %d" % (service, r.status))
        return r.status, data


def db_query(tracer, table, ms):
    with tracer.span("db.query " + table) as s:
        s.set("db.statement", "SELECT * FROM %s WHERE student_id = ?" % table)
        time.sleep((ms + random.randint(0, ms // 2)) / 1000)


def gateway(t, sid):
    return call(t, "report", "/report?student=%d" % sid)


def report(t, sid):
    code, student = call(t, "students", "/students/%d" % sid)
    if code != 200:
        return code, student
    code, grades = call(t, "grades", "/grades/%d" % sid)
    with t.span("build report"):
        time.sleep(0.01)
        return code, {"student": student["name"], "grades": grades.get("grades", [])}


def students(t, sid):
    db_query(t, "students", 20)
    if sid not in STUDENTS:
        return 404, {"error": "студент табылмады"}
    return 200, {"id": sid, "name": STUDENTS[sid]}


def grades(t, sid):
    with t.span("cache.get") as s:
        time.sleep(0.003)
        s.set("cache.hit", False)
    db_query(t, "grades", 30)
    if sid in ARCHIVE:
        db_query(t, "grades_archive", 1200)               # баяу: индекссіз ескі кесте
    return 200, {"id": sid, "grades": GRADES.get(sid, [])}


def make_handler(name, logic):
    tracer = Tracer(name)

    class Handler(BaseHTTPRequestHandler):
        def do_GET(self):
            u = urlsplit(self.path)
            with tracer.span("GET " + u.path.rstrip("/0123456789") or "/", kind="server", headers=self.headers) as s:
                q = parse_qs(u.query)
                sid = int(q.get("student", [u.path.rsplit("/", 1)[-1]])[0])
                s.set("student.id", sid)
                code, data = logic(tracer, sid)
                s.set("http.status_code", code)
                if code >= 400:
                    s.error("HTTP %d" % code)
            body = json.dumps(data, ensure_ascii=False).encode("utf-8")
            self.send_response(code)
            self.send_header("Content-Type", "application/json; charset=utf-8")
            self.send_header("Content-Length", str(len(body)))
            self.send_header("X-Trace-ID", s.trace_id)
            self.end_headers()
            self.wfile.write(body)

        def log_message(self, *args):
            pass

    return Handler


for name, logic in (("gateway", gateway), ("report", report), ("students", students), ("grades", grades)):
    server = ThreadingHTTPServer(("127.0.0.1", PORTS[name]), make_handler(name, logic))
    threading.Thread(target=server.serve_forever, daemon=True).start()
    print("іске қосылды: %-9s http://127.0.0.1:%d" % (name, PORTS[name]))

while True:
    time.sleep(1)

# view_trace.py — трассаларды талдау (Jaeger UI-дің мәтіндік нұсқасы)
#   python3 view_trace.py                 — соңғы трассалар тізімі
#   python3 view_trace.py <trace_id>      — бір трассаның «сарқырамасы» (waterfall)
#   python3 view_trace.py slowest         — ең баяу трасса
import collections
import json
import sys

FILE = "traces/spans.jsonl"
spans = [json.loads(line) for line in open(FILE, encoding="utf-8") if line.strip()]
traces = collections.defaultdict(list)
for s in spans:
    traces[s["trace_id"]].append(s)


def root(trace):
    return next((s for s in trace if not s["parent_id"]), min(trace, key=lambda s: s["start_us"]))


def summary():
    print("%-32s  %-14s %9s %5s %6s" % ("trace_id", "түбір", "мс", "span", "қате"))
    for tid, tr in list(traces.items())[-15:]:
        r = root(tr)
        errors = sum(s["status"] == "ERROR" for s in tr)
        print("%-32s  %-14s %9.1f %5d %6s" % (tid, r["service"] + " " + r["name"].split()[-1], r["duration_ms"], len(tr), errors or ""))


def waterfall(tid):
    tr = traces[tid]
    r = root(tr)
    t0, total = r["start_us"], max(r["duration_ms"], 0.1)
    children = collections.defaultdict(list)
    for s in tr:
        children[s["parent_id"]].append(s)
    print("Трасса %s: %d span, %.1f мс\n" % (tid, len(tr), total))

    def show(s, depth):
        left = int((s["start_us"] - t0) / 1000 / total * 40)
        width = max(1, int(s["duration_ms"] / total * 40))
        bar = " " * left + "█" * width
        mark = "  ← ҚАТЕ: " + s["attrs"].get("error.message", "") if s["status"] == "ERROR" else ""
        print("%-44s |%-41s| %8.1f мс%s" % ("  " * depth + s["service"] + ": " + s["name"], bar, s["duration_ms"], mark))
        for c in sorted(children[s["span_id"]], key=lambda c: c["start_us"]):
            show(c, depth + 1)
    show(r, 0)
    own = max((s for s in tr if not children[s["span_id"]]), key=lambda s: s["duration_ms"])
    print("\nЕң ұзақ «жапырақ» span: %s: %s — %.1f мс (%.0f%%)" % (own["service"], own["name"], own["duration_ms"],
                                                               own["duration_ms"] / total * 100))


if len(sys.argv) == 1:
    summary()
elif sys.argv[1] == "slowest":
    waterfall(max(traces, key=lambda t: root(traces[t])["duration_ms"]))
else:
    waterfall(sys.argv[1])

  2. 2-терминал: 1, 2, 3, 4 және 99 студенттер үшін сұрау жіберіңіз: curl "http://127.0.0.1:8200/report?student=1" ... Жауаптың X-Trace-ID тақырыбын curl -i арқылы көріңіз.
  3. python3 view_trace.py → трассалар тізімі: әрқайсысында 11–12 span, біреуі баяу (≈ 1500 мс), біреуінде қате бар.
  4. python3 view_trace.py slowest → сарқырама. Баяулаудың себебін табыңыз: қай сервис, қай операция, жалпы уақыттың неше пайызы? (Күтілетін нәтиже: grades: db.query grades_archive, ≈ 94%.)
  5. Қатесі бар трассаны ашыңыз (python3 view_trace.py <trace_id>): қате қай сервистен басталып, қалай жоғары қарай таралды?
  6. Түсіндіріңіз: неге gateway-дің уақыты барлық ішкі span-дардың уақытын қамтиды? Журналдармен салыстырғанда трассировканың артықшылығы неде?

Есепке: services.py және view_trace.py, трассалар тізімі, баяу және қатесі бар трассаның сарқырамасы, табылған себеп, сұрақтарға жауап.

3-тапсырма. Агентті баптау: sampling, Jaeger, жеке нұсқа (20 мин, 30 ұпай)

Нақты жүйеде секундына мыңдаған сұрау болады, сондықтан барлығы емес, бір бөлігі ғана жазылады (sampling). Агент кодты өзгертпей, орта айнымалыларымен бапталады — OpenTelemetry агенттері де дәл солай бапталады (OTEL_SERVICE_NAME, OTEL_TRACES_SAMPLER_ARG, OTEL_EXPORTER_OTLP_ENDPOINT).

  1. Sampling: сервистерді тоқтатып, traces қалтасын өшіріңіз. TRACE_SAMPLE_RATE=0.2 python3 services.py. 20 сұрау жіберіңіз (Mac: for i in $(seq 1 20); do curl -s "http://127.0.0.1:8200/report?student=1" > /dev/null; done) → python3 view_trace.py ≈ 4 трасса. Неге трассаның барлық span-ы бірге не жазылады, не жазылмайды (traceparent-тегі 01 / 00 флагы)?
  2. Jaeger (Docker болса): docker run --rm --name jaeger -e COLLECTOR_OTLP_ENABLED=true -p 16686:16686 -p 4318:4318 jaegertracing/all-in-one:latest. Сервистерді OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4318 python3 services.py арқылы қайта іске қосып, бірнеше сұрау жіберіңіз. Браузерде http://localhost:16686 → Service: gateway → Find Traces. Сарқырамаңызды Jaeger-дегімен салыстырыңыз. Docker болмаса — оқытушының демонстрациясын қараңыз.
  3. Нұсқаңыз бойынша тапсырманы орындаңыз (өз жұмысыңыз).
  4. Түсіндіріңіз: head-based sampling дегеніміз не және оның кемшілігі (сирек қатені өткізіп алу)? Агентті неге кодпен емес, орта айнымалыларымен баптаған ыңғайлы?

Бақылау сұрақтары

  1. Distributed Tracing дегеніміз не және ол журналдар мен метрикалардан немен ерекшеленеді?
  2. Trace және span дегеніміз не? Span-да қандай мәліметтер сақталады?
  3. trace_id, span_id, parent_id не үшін керек?
  4. W3C traceparent тақырыбының құрылымы қандай?
  5. Контекст сервистер арасында қалай беріледі (inject / extract)?
  6. Server, client және internal span-дардың айырмашылығы неде?
  7. Sampling дегеніміз не? Head-based және tail-based sampling айырмашылығы?
  8. Jaeger қандай бөліктерден тұрады (агент/SDK, collector, storage, UI)?
  9. OpenTelemetry дегеніміз не және OTLP хаттамасы не үшін керек?
  10. Сарқырама (waterfall) бойынша баяулаудың себебін қалай табасыз?
