1. Орталар: Dev, Test, Prod

Бір код бірнеше жерде жұмыс істейді. Код бірдей, ал конфигурация (порт, дерекқор, журнал деңгейі, құпиялар) әр ортада әртүрлі.

ОртаКімгеЕрекшелігі
Devәзірлеушіdebug қосулы, толық журнал, жергілікті ДҚ, жаңа функциялар қосулы
Testтестілеуші, CIprod-қа ұқсас, тест деректер, жеке ДҚ
Prodнақты пайдаланушыларdebug өшірулі, тек қателер журналы, нақты ДҚ, қатаң құпиялар
Ең жиі кездесетін қате: prod-қа dev конфигурациясы кетеді (debug қосулы — қателердің ішкі мәліметі пайдаланушыға көрінеді) немесе құпиясөз Git-ке түседі.

2. Конфигурация файлдары

base.json — барлық ортаға ортақ мәндер; dev.json, test.json, prod.json — тек айырмашылықтар. Олар терең біріктіріледі: ішкі сөздіктің бір кілті ғана өзгерсе, қалғандары сақталады.

base.json:  "db": {"host": "localhost", "port": 5432, "name": "college"}
prod.json:  "db": {"host": "db.aec.kz"}
нәтиже:     "db": {"host": "db.aec.kz", "port": 5432, "name": "college"}

3. Орта айнымалылары және .env

Орта айнымалысы — операциялық жүйе бағдарламаға беретін «аты = мәні» жұбы. Құпиялар (құпиясөз, кілт) кодта да, JSON-да да емес, орта айнымалыларында немесе .env файлында сақталады.

# Mac / Linux
APP_ENV=prod APP_PORT=9090 python3 show_config.py
# Windows PowerShell
$env:APP_PORT="9090"; python show_config.py prod

# .env (Git-ке САЛЫНБАЙДЫ — .gitignore)
APP_DB__PASSWORD=dev-pass-123
# .env.example (Git-те — қандай айнымалылар керегін көрсетеді, мәнсіз)
APP_DB__PASSWORD=

APP_DB__PASSWORD → {"db": {"password": ...}}: APP_ — біздің қосымшаның белгісі, __ — ішкі деңгей.

5. Конфигурацияны тексеру

Қате конфигурация — қате кодтай қауіпті. Сондықтан CI құбырында деплойдан бұрын тексеру іске қосылады: міндетті кілттер, порт, журнал деңгейі, prod-та debug өшірулі ме, JSON-да құпия жоқ па.

# settings.py — ортаға (dev / test / prod) сай конфигурацияны жинау
# Басымдық (төменгісі жоғарғысын басады):
#   1) config/base.json      — барлық ортаға ортақ мәндер
#   2) config/<орта>.json    — сол ортаның айырмашылықтары
#   3) .env файлы            — құпиялар (Git-ке салынбайды)
#   4) жүйенің орта айнымалылары (APP_...) — ең жоғары басымдық
import json
import os

PREFIX = "APP_"


def read_env_file(path=".env"):
    """KEY=VALUE жолдарын оқиды (# — түсініктеме)."""
    values = {}
    if os.path.exists(path):
        for line in open(path, encoding="utf-8"):
            line = line.strip()
            if line and not line.startswith("#") and "=" in line:
                key, value = line.split("=", 1)
                values[key.strip()] = value.strip()
    return values


def merge(base, extra):
    """Сөздіктерді терең біріктіру: ішкі сөздіктер де бірігеді."""
    result = dict(base)
    for key, value in extra.items():
        if isinstance(value, dict) and isinstance(result.get(key), dict):
            result[key] = merge(result[key], value)
        else:
            result[key] = value
    return result


def convert(text):
    """Жолды типке айналдыру: "true" -> True, "8080" -> 8080."""
    if text.lower() in ("true", "false"):
        return text.lower() == "true"
    if text.isdigit():
        return int(text)
    return text


def from_variables(variables):
    """APP_DB__PASSWORD=x  ->  {"db": {"password": "x"}}  (__ — ішкі деңгей)."""
    result = {}
    for key, value in variables.items():
        if not key.startswith(PREFIX) or key == PREFIX + "ENV":
            continue
        parts = key[len(PREFIX):].lower().split("__")
        node = result
        for part in parts[:-1]:
            node = node.setdefault(part, {})
        node[parts[-1]] = convert(value)
    return result


def load(env=None):
    env_file = read_env_file()
    env = env or os.environ.get("APP_ENV") or env_file.get("APP_ENV") or "dev"
    path = os.path.join("config", env + ".json")
    if not os.path.exists(path):
        raise SystemExit("ҚАТЕ: '%s' ортасы жоқ (config/%s.json табылмады)" % (env, env))
    config = json.load(open(os.path.join("config", "base.json"), encoding="utf-8"))
    config = merge(config, json.load(open(path, encoding="utf-8")))
    config = merge(config, from_variables(env_file))
    config = merge(config, from_variables(os.environ))
    config["env"] = env
    return config

# show_config.py — ортаның соңғы конфигурациясын көрсету (құпиялар жасырылады)
#   python3 show_config.py dev | test | prod
import json
import sys

from settings import load

SECRET_WORDS = ("password", "secret", "token", "key")


def mask(data):
    result = {}
    for key, value in data.items():
        if isinstance(value, dict):
            result[key] = mask(value)
        elif any(word in key for word in SECRET_WORDS) and value:
            result[key] = "***"
        else:
            result[key] = value
    return result


env = sys.argv[1] if len(sys.argv) > 1 else None
config = load(env)
print("Орта:", config["env"])
print(json.dumps(mask(config), ensure_ascii=False, indent=2))

# check_config.py — барлық орталардың конфигурациясын тексеру (CI-де іске қосылады)
#   python3 check_config.py   -> қате болса шығу коды 1
import json
import os
import sys

from settings import load

REQUIRED = ["app_name", "port", "debug", "log_level", "db"]
LEVELS = ["DEBUG", "INFO", "WARNING", "ERROR"]
errors = 0


def problem(env, text):
    global errors
    errors += 1
    print("  [ҚАТЕ] %s: %s" % (env, text))


# 1) JSON файлдарында құпия болмауы керек
for name in sorted(os.listdir("config")):
    text = open(os.path.join("config", name), encoding="utf-8").read().lower()
    for word in ("password", "secret"):
        if word in text:
            problem(name, "құпия (%s) JSON файлда тұр — оны .env-ке көшіріңіз" % word)

# 2) әр ортаның жиналған конфигурациясы
for env in ["dev", "test", "prod"]:
    print("%s ортасы:" % env)
    c = load(env)
    for key in REQUIRED:
        if key not in c:
            problem(env, "міндетті кілт жоқ: " + key)
    if not isinstance(c.get("port"), int) or not 1 <= c["port"] <= 65535:
        problem(env, "port 1–65535 аралығындағы сан болуы керек")
    if c.get("log_level") not in LEVELS:
        problem(env, "log_level: " + str(c.get("log_level")))
    if env == "prod" and c.get("debug"):
        problem(env, "prod ортасында debug қосулы болмауы керек")
    if env == "prod" and c["db"].get("host") == "localhost":
        problem(env, "prod дерекқоры localhost бола алмайды")
    print("  тексерілді: debug=%s, log_level=%s, db=%s/%s" % (c["debug"], c["log_level"], c["db"]["host"], c["db"]["name"]))

print("Қате саны:", errors)
sys.exit(1 if errors else 0)
  1. python3 check_config.py; echo $? → үш орта тексерілді, «Қате саны: 0», 0.
  2. Қатені әдейі енгізіңіз: prod.json-ға "debug": true қосыңыз → «[ҚАТЕ] prod: prod ортасында debug қосулы болмауы керек», шығу коды 1. Содан кейін prod.json-ға "password": "123" жазып көріңіз → тағы бір қате. Екеуін де алып тастаңыз.
  3. Нұсқаңыз бойынша тапсырманы орындаңыз (өз жұмысыңыз).
  4. Түсіндіріңіз: бұл тексеру CI/CD-де қай кезеңде іске қосылады және неге?

Бақылау сұрақтары

  1. Dev, Test, Prod орталары бір-бірінен немен ерекшеленеді?
  2. Орта айнымалысы дегеніміз не? Оны Mac және Windows-та қалай береді?
  3. Неге құпиялар кодта және JSON-да емес, .env-те немесе орта айнымалыларында сақталады?
  4. .env мен .env.example айырмашылығы қандай?
  5. Сіздің settings.py-дегі басымдық тәртібі қандай және неге дәл осындай?
  6. Терең біріктіру (deep merge) дегеніміз не?
  7. 12-Factor App-тың «Config» қағидасы не дейді?
  8. Feature flag дегеніміз не және оны орталар бойынша қалай қолданады?
  9. check_config.py-ді CI/CD-де қай кезеңде іске қосқан дұрыс?
  10. Нақты жобаларда құпиялар қайда сақталады (Vault, GitHub Secrets, Kubernetes Secrets)?
