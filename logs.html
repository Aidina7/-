1. Неге логтарды орталыққа жинайды?

Әр сервер логын өз дискісіне жазады: /var/log/nginx/access.log, қосымшаның логы, /var/log/auth.log. Серверлер көп болғанда қатенің себебін табу үшін әр серверге кіріп, grep жасау керек. Сервер құласа немесе шабуылдаушы логты өшірсе, дерек жоғалады.

Орталықтандырылған лог жинау — барлық сервердің логтарын бір жерге жинап, бірыңғай түрге келтіріп, бір жерден іздеу және талдау.

Бір жерден іздеу

«Соңғы сағаттағы барлық ERROR» — бір сұраумен, барлық серверден.

Корреляция

web-тегі 502 мен app-тегі «database timeout» бір уақытта болғанын көру.

Қауіпсіздік

Логтың көшірмесі серверден тыс сақталады — шабуылдаушы оны өшіре алмайды.

Ескерту

Брутфорс, қателердің күрт өсуі туралы автоматты хабар.

3. Парсинг және нормализация

Құрылымсыз лог — жай мәтін жолы. Парсинг оны өрістерге бөледі, сонда «статусы 500 жолдар» немесе «IP бойынша санау» мүмкін болады. Әдетте тұрақты өрнектердің (regex) атаулы топтары қолданылады (Logstash-та — grok үлгілері).

10.0.0.7 - - [26/Nov/2026:14:20:01 +0500] "GET /journal HTTP/1.1" 502 157

NGINX = re.compile(r'(?P<ip>\S+) \S+ \S+ \[(?P<time>[^\]]+)\] "(?P<method>\S+) '
                   r'(?P<path>\S+) [^"]*" (?P<status>\d{3}) (?P<bytes>\d+)')
# → {"ip": "10.0.0.7", "status": 502, "path": "/journal", "level": "ERROR", ...}

Нормализация — әртүрлі форматтарды бірыңғай түрге келтіру. Үш сервердің уақыты: 26/Nov/2026:14:20:01, 2026-11-26 14:20:01, Nov 26 14:20:01 → бәрі ISO 8601. Деңгейлер: WARNING → WARN, HTTP 5xx → ERROR.

Ең жақсы шешім — қосымша логты бірден JSON түрінде жазса (құрылымды логтар): парсинг қажет емес.

4. Агенттің сенімділігі

Offset (registry)

Әр файлдың қай байтқа дейін оқылғаны дискіде сақталады. Агент қайта қосылса — логтар қайталанбайды.

Ротация

logrotate access.log-ты access.log.1 етіп ауыстырады. Агент оны inode өзгергенінен немесе файл қысқарғанынан таниды.

Multiline

Traceback бірнеше жолдан тұрады. Жаңа жазба күнмен басталады, қалған жолдар алдыңғысына жалғанады.

Буфер

Жинағыш қолжетімсіз болса — логтар буферде күтеді. Offset тек жеткізілгеннен кейін сақталады: at-least-once.

{"servers/web/access.log": {"offset": 9154, "inode": 811474}}   # registry.json

# gen_logs.py — үш сервердің логтарын жасайды: web (nginx), app (Python), auth (sshd, syslog)
#   python3 gen_logs.py              — секундына 3 жол, тоқтағанша (Ctrl+C)
#   python3 gen_logs.py --once 300   — 300 жол жазып, тоқтайды
#   python3 gen_logs.py --rotate     — логтарды ротациялау: access.log -> access.log.1
import datetime
import os
import random
import sys
import time

FILES = {"web": "servers/web/access.log", "app": "servers/app/app.log", "auth": "servers/auth/auth.log"}
IPS = ["10.0.0.%d" % i for i in range(2, 12)] + ["185.220.101.7", "45.13.9.88"]
PATHS = ["/", "/login", "/journal", "/api/grades", "/api/students", "/static/app.js"]
USERS = ["aigerim", "nurlan", "daulet", "teacher", "admin", "root"]
MODULES = ["grades", "students", "auth", "schedule"]


def web(now):
    status = random.choice([200, 200, 200, 200, 200, 301, 304, 404, 404, 500, 502])
    return '%s - - [%s] "%s %s HTTP/1.1" %d %d "-" "Mozilla/5.0"' % (
        random.choice(IPS), now.strftime("%d/%b/%Y:%H:%M:%S +0500"), random.choice(["GET", "GET", "POST"]),
        random.choice(PATHS), status, random.randint(120, 9000))


def app(now):
    t = now.strftime("%Y-%m-%d %H:%M:%S,") + "%03d" % random.randint(0, 999)
    module = random.choice(MODULES)
    r = random.random()
    if r < 0.12:
        return ("%s ERROR [%s] Деректер базасына қосылу мүмкін болмады\n"
                "Traceback (most recent call last):\n"
                '  File "app.py", line 42, in get_%s\n'
                "    conn = db.connect(timeout=3)\n"
                "ConnectionError: database timeout after 3s" % (t, module, module))
    if r < 0.3:
        return "%s WARNING [%s] Сұрау баяу орындалды: %d мс" % (t, module, random.randint(800, 2500))
    return "%s INFO [%s] Сұрау өңделді: user=%s %d мс" % (t, module, random.choice(USERS[:4]), random.randint(5, 120))


def auth(now):
    t = "%s %2d %s" % (now.strftime("%b"), now.day, now.strftime("%H:%M:%S"))     # Nov 26 14:20:01
    ip, user = random.choice(IPS), random.choice(USERS)
    if ip.startswith("10.") and user not in ("admin", "root"):
        msg = "Accepted password for %s from %s port %d ssh2" % (user, ip, random.randint(40000, 60000))
    else:
        msg = "Failed password for %s from %s port %d ssh2" % (user, ip, random.randint(40000, 60000))
    return "%s auth-01 sshd[%d]: %s" % (t, random.randint(1000, 9999), msg)


def write(n):
    for _ in range(n):
        service = random.choice(["web", "web", "app", "auth"])
        line = {"web": web, "app": app, "auth": auth}[service](datetime.datetime.now())
        os.makedirs(os.path.dirname(FILES[service]), exist_ok=True)
        with open(FILES[service], "a", encoding="utf-8") as f:
            f.write(line + "\n")


if "--rotate" in sys.argv:
    for path in FILES.values():
        if os.path.exists(path):
            os.replace(path, path + ".1")
            print("ротация:", path, "->", path + ".1")
elif "--once" in sys.argv:
    n = int(sys.argv[sys.argv.index("--once") + 1])
    write(n)
    print(n, "жол жазылды")
else:
    print("Логтар жазылып жатыр (Ctrl+C — тоқтату)...")
    while True:
        write(3)
        time.sleep(1)

2-тапсырма. Орталық жинағыш және агент (25 мин, 15 ұпай)

Агент әр серверде тұрады: файлдарға жаңа жол қосылғанын бақылайды да, оларды топтамамен (batch) жинағышқа HTTP арқылы жібереді. Жинағыш оқиғаларды күн бойынша файлдарға (storage/2026-11-26.jsonl) сақтайды және іздеуге мүмкіндік береді. Бұл тапсырмада бірнеше функция «бос» (заглушка) — оларды 3–5-тапсырмаларда ауыстырасыз.

Файл: collector.py

# collector.py — орталық лог жинағыш (Logstash / Loki-дің оқу нұсқасы)
#   python3 collector.py          — http://127.0.0.1:9200
#   POST /ingest   — агенттерден логтар топтамасын қабылдау
#   GET  /search   — іздеу: ?service=app&level=ERROR&q=timeout&limit=20
#   GET  /stats    — агрегация: ?field=status&service=web
import collections
import datetime
import json
import os
import re
import threading
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer
from urllib.parse import parse_qs, urlsplit

PORT = 9200
STORE = "storage"
LOCK = threading.Lock()
SPECIAL = ("q", "limit", "field")

# ===== Төмендегі 2 функция әзірге «бос» (заглушка). 3 және 5-тапсырмаларда толық кодпен АУЫСТЫРАСЫЗ =====
def parse(parser, line):            # 3-тапсырмада ауыстырасыз
    return None


def aggregate(events, field):       # 5-тапсырмада ауыстырасыз
    return {}


def store(events):
    os.makedirs(STORE, exist_ok=True)
    path = os.path.join(STORE, datetime.date.today().isoformat() + ".jsonl")   # күн сайын жаңа файл
    with LOCK, open(path, "a", encoding="utf-8") as f:
        for e in events:
            f.write(json.dumps(e, ensure_ascii=False) + "\n")


def load():
    if not os.path.isdir(STORE):
        return
    for name in sorted(os.listdir(STORE)):
        with open(os.path.join(STORE, name), encoding="utf-8") as f:
            for line in f:
                yield json.loads(line)


def match(e, query):
    for k, v in query.items():
        if k == "q":
            if v.lower() not in e.get("message", "").lower():
                return False
        elif k not in SPECIAL and str(e.get(k, "")) != v:
            return False
    return True


class Collector(BaseHTTPRequestHandler):
    def reply(self, code, data):
        body = json.dumps(data, ensure_ascii=False, indent=1).encode("utf-8")
        self.send_response(code)
        self.send_header("Content-Type", "application/json; charset=utf-8")
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)

    def do_POST(self):
        if self.path != "/ingest":
            return self.reply(404, {"error": "тек /ingest"})
        try:
            batch = json.loads(self.rfile.read(int(self.headers.get("Content-Length") or 0)))
        except ValueError:
            return self.reply(400, {"error": "JSON қате"})
        now, events, bad = datetime.datetime.now().isoformat(timespec="seconds"), [], 0
        for item in batch["events"]:
            ev = parse(item["parser"], item["line"])
            if ev is None:
                ev, bad = {"message": item["line"], "parse_error": True}, bad + 1
            ev.setdefault("@timestamp", now)
            ev.update(service=item["service"], host=item["host"], file=item["file"], received=now)
            ev.update(batch.get("labels", {}))
            events.append(ev)
        store(events)
        print("[ingest] %s: %d оқиға, парсинг қатесі: %d" % (batch.get("agent"), len(events), bad))
        self.reply(200, {"accepted": len(events), "parse_errors": bad})

    def do_GET(self):
        u = urlsplit(self.path)
        query = {k: v[0] for k, v in parse_qs(u.query).items()}
        found = [e for e in load() if match(e, query)]
        if u.path == "/search":
            limit = int(query.get("limit", 20))
            return self.reply(200, {"total": len(found), "events": found[-limit:]})
        if u.path == "/stats":
            return self.reply(200, {"field": query.get("field"), "total": len(found),
                                    "counts": aggregate(found, query.get("field", "service"))})
        if u.path == "/health":
            return self.reply(200, {"status": "ok"})
        self.reply(404, {"error": "белгісіз жол"})

    def log_message(self, *args):
        pass


print("Орталық лог жинағыш: http://127.0.0.1:%d (сақтау орны: %s/)" % (PORT, STORE))
ThreadingHTTPServer(("127.0.0.1", PORT), Collector).serve_forever()

def read_new(inp, reg):
    """Файлдың соңғы оқылған жерінен бастап жаңа толық жолдарды оқу."""
    path = inp["path"]
    if not os.path.exists(path):
        return []
    info = reg.get(path)
    pos = 0 if rotated(path, info) else (info or {}).get("offset", 0)
    if info and pos == 0:
        print("[agent] %s ротацияланды — басынан оқимыз" % path)
    with open(path, "rb") as f:
        f.seek(pos)
        raw = f.read()
    end = raw.rfind(b"\n") + 1                       # тек толық жазылған жолдар
    reg[path] = {"offset": pos + end, "inode": os.stat(path).st_ino}
    return raw[:end].decode("utf-8", errors="replace").splitlines()


def send(batch):
    body = {"agent": CONF["name"], "labels": CONF["labels"], "events": batch}
    req = urllib.request.Request(CONF["output"] + "/ingest", data=json.dumps(body, ensure_ascii=False).encode("utf-8"),

def ship(events):
    """Топтамалармен (batch) жіберу; жинағыш қолжетімсіз болса — буферде сақтау."""
    global BUFFER
    BUFFER += events
    while BUFFER:
        batch = BUFFER[:CONF["batch_size"]]
        try:
            send(batch)
        except OSError as e:

            print("[agent] жинағыш қолжетімсіз (%s), буферде %d оқиға" % (type(e).__name__, len(BUFFER)))
            return
        BUFFER = BUFFER[len(batch):]
        print("[agent] жіберілді: %d оқиға" % len(batch))

NGINX = re.compile(r'(?P<ip>\S+) \S+ \S+ \[(?P<time>[^\]]+)\] "(?P<method>\S+) (?P<path>\S+) [^"]*" '
                   r'(?P<status>\d{3}) (?P<bytes>\d+)')
APP = re.compile(r"(?P<time>\d{4}-\d\d-\d\d \d\d:\d\d:\d\d),\d+ (?P<level>[A-Z]+) \[(?P<module>\w+)\] (?P<msg>.*)", re.S)
SYSLOG = re.compile(r"(?P<time>\w{3} +\d+ [\d:]+) (?P<host>\S+) (?P<prog>\w+)\[\d+\]: (?P<msg>.*)")
SSH = re.compile(r"(?P<result>Failed|Accepted) password for (?P<user>\S+) from (?P<ip>\S+)")


def parse(parser, line):
    """parser: nginx | app | syslog. Танылмаса — None."""
    if parser == "nginx":
        m = NGINX.match(line)
        if not m:
            return None
        d = m.groupdict()
        status = int(d["status"])
        ts = datetime.datetime.strptime(d["time"], "%d/%b/%Y:%H:%M:%S %z").replace(tzinfo=None)
        return {"@timestamp": ts.isoformat(), "level": "ERROR" if status >= 500 else "WARN" if status >= 400 else "INFO",
                "ip": d["ip"], "method": d["method"], "path": d["path"], "status": status, "bytes": int(d["bytes"]),
                "message": line}
    if parser == "app":
        m = APP.match(line)
        if not m:
            return None
        d = m.groupdict()
        ev = {"@timestamp": datetime.datetime.strptime(d["time"], "%Y-%m-%d %H:%M:%S").isoformat(),
              "level": "WARN" if d["level"] == "WARNING" else d["level"], "module": d["module"],
              "message": d["msg"].split("\n")[0]}
        if "Traceback" in d["msg"]:
            ev["exception"] = d["msg"].strip().split("\n")[-1]          # соңғы жол: қатенің түрі
            ev["stacktrace"] = d["msg"]
        return ev
    if parser == "syslog":
        m = SYSLOG.match(line)
        if not m:
            return None
        d = m.groupdict()
        ts = datetime.datetime.strptime("%d %s" % (datetime.date.today().year, d["time"]), "%Y %b %d %H:%M:%S")
        ev = {"@timestamp": ts.isoformat(), "level": "INFO", "program": d["prog"], "message": d["msg"]}
        s = SSH.search(d["msg"])
        if s:
            ev.update(user=s["user"], ip=s["ip"], auth="fail" if s["result"] == "Failed" else "ok")
            if s["result"] == "Failed":
                ev["level"] = "WARN"
        return ev
    return None

def load_registry():
    """Әр файлдың қай жерге дейін оқылғанын (offset) дискіден оқу."""
    if os.path.exists(REGISTRY):
        with open(REGISTRY, encoding="utf-8") as f:
            return json.load(f)
    return {}


def save_registry(reg):
    tmp = REGISTRY + ".tmp"
    with open(tmp, "w", encoding="utf-8") as f:
        json.dump(reg, f, indent=1)
    os.replace(tmp, REGISTRY)                    # атомарлы жазу: файл жартылай қалмайды


def rotated(path, info):
    """Файл ауыстырылды ма (басқа inode) немесе қысқарды ма?"""
    if not info:
        return False
    st = os.stat(path)
    return st.st_ino != info["inode"] or st.st_size < info["offset"]


def join_multiline(lines, pattern):
    """Жаңа жазба pattern-мен басталады; қалған жолдар (Traceback) алдыңғысына жалғанады."""
    start, out = re.compile(pattern), []
    for line in lines:
        if out and not start.match(line):
            out[-1] += "\n" + line
        else:
            out.append(line)
    return out

def aggregate(events, field):
    """field мәндері бойынша санау, көбінен азына қарай."""
    counts = collections.Counter(str(e.get(field, "—")) for e in events)
    return dict(counts.most_common(20))

import csv
import json
import os

COLLECTOR = ("127.0.0.1", 9200)
FB_PARSER = {"nginx": "nginx", "app": "app", "syslog": "syslog-rfc3164"}

hosts = {}
with open("servers.csv", encoding="utf-8") as f:
    for row in csv.DictReader(f):
        hosts.setdefault(row["host"], []).append(row)

for host, rows in hosts.items():
    os.makedirs("configs/" + host, exist_ok=True)
    agent = {
        "name": host,
        "output": "http://%s:%d" % COLLECTOR,
        "labels": {"env": rows[0]["env"], "college": "aec"},
        "batch_size": 100, "interval": 2, "buffer_max": 5000,
        "registry": "configs/%s/registry.json" % host,
        "inputs": [],
    }
    fb = ["[SERVICE]", "    Flush         2", "    Log_Level     info", "    Parsers_File  parsers.conf", ""]
    for r in rows:
        inp = {"path": r["path"], "parser": r["parser"], "service": r["service"], "host": host}
        if r["multiline"]:
            inp["multiline"] = r["multiline"]
        agent["inputs"].append(inp)
        fb += ["[INPUT]", "    Name              tail", "    Path              " + r["path"],
               "    Tag               " + r["service"], "    DB                /var/lib/fluent-bit/%s.db" % r["service"]]
        if r["multiline"]:
            fb.append("    multiline.parser  python")
        fb += ["", "[FILTER]", "    Name      parser", "    Match     " + r["service"], "    Key_Name  log",
               "    Parser    " + FB_PARSER[r["parser"]], ""]
    fb += ["[FILTER]", "    Name    record_modifier", "    Match   *", "    Record  host " + host,
           "    Record  env " + rows[0]["env"], "",
           "[OUTPUT]", "    Name    http", "    Match   *", "    Host    %s" % COLLECTOR[0], "    Port    %d" % COLLECTOR[1],
           "    URI     /ingest", "    Format  json", ""]
    with open("configs/%s/agent.json" % host, "w", encoding="utf-8") as f:
        json.dump(agent, f, ensure_ascii=False, indent=2)
    with open("configs/%s/fluent-bit.conf" % host, "w", encoding="utf-8") as f:

PARSERS = {"nginx", "app", "syslog"}
ENVS = {"dev", "test", "prod"}
files = sys.argv[1:] or sorted(glob.glob("configs/*/agent.json"))
errors, warnings, registries, paths = [], [], {}, {}

for fn in files:
    try:
        c = json.load(open(fn, encoding="utf-8"))
    except (OSError, ValueError) as e:
        errors.append("%s: оқылмады: %s" % (fn, e))
        continue
    if not re.fullmatch(r"https?://[\w.-]+:\d+", c.get("output", "")):
        errors.append("%s: output 'http://хост:порт' түрінде болуы керек" % fn)
    if c.get("labels", {}).get("env") not in ENVS:
        errors.append("%s: labels.env — dev, test немесе prod" % fn)
    if not 1 <= c.get("batch_size", 0) <= 1000:
        errors.append("%s: batch_size 1–1000 аралығында болуы керек" % fn)
    if not 1 <= c.get("interval", 0) <= 60:
        errors.append("%s: interval 1–60 секунд" % fn)
    reg = c.get("registry", "registry.json")
    if reg in registries:
        errors.append("%s: registry '%s' %s-пен ортақ — офсеттер бір-бірін бұзады" % (fn, reg, registries[reg]))
    registries[reg] = fn
    if not c.get("inputs"):
        errors.append("%s: inputs бос" % fn)
    for inp in c.get("inputs", []):
        if inp.get("parser") not in PARSERS:
            errors.append("%s: %s — белгісіз парсер '%s'" % (fn, inp.get("path"), inp.get("parser")))
        if "multiline" in inp:
            try:
                re.compile(inp["multiline"])
            except re.error as e:
                errors.append("%s: multiline үлгісі қате: %s" % (fn, e))
        if inp.get("path") in paths:
            warnings.append("%s: %s файлын %s та оқиды — логтар екі рет келеді" % (fn, inp["path"], paths[inp["path"]]))
        paths[inp.get("path")] = fn
        if not os.path.exists(inp.get("path", "")):
            warnings.append("%s: %s әзірге жоқ" % (fn, inp.get("path")))

for w in warnings:
    print("  [ЕСКЕРТУ]", w)
for e in errors:
    print("  [ҚАТЕ]", e)
print("Тексерілді: %d файл. Қате: %d, ескерту: %d" % (len(files), len(errors), len(warnings)))
sys.exit(1 if errors else 0)
  1. python3 build_agents.py → configs/web-01, app-01, auth-01 қалталары. python3 check_agent.py; echo $? → «Қате: 0», 0 (Windows: echo $LASTEXITCODE).
  2. Бұрынғы агентті тоқтатып, үш агентті үш терминалда іске қосыңыз: python3 agent.py configs/web-01/agent.json т.с.с. Әрқайсысы тек өз файлын жібереді: python3 logq.py --count host.
  3. Қате енгізіңіз: web-01/agent.json-да парсерді apache, registry-ді app-01-дікімен бірдей етіңіз → check_agent.py екі қатені табады, шығу коды 1. python3 build_agents.py арқылы қайта жасаңыз.
  4. configs/app-01/fluent-bit.conf файлын ашып, agent.json-мен салыстырыңыз (кесте: agent.json өрісі → Fluent Bit бөлімі мен параметрі).

Бақылау сұрақтары

  1. Орталықтандырылған лог жинау дегеніміз не және ол қандай мәселелерді шешеді?
  2. Лог жинау жүйесі қандай бөліктерден тұрады (агент, жинағыш/өңдеуші, сақтау орны, визуализация)?
  3. ELK / EFK стегі және Loki нені білдіреді? Агент ретінде қандай бағдарламалар қолданылады?
  4. Парсинг дегеніміз не? Құрылымсыз және құрылымды логтың айырмашылығы?
  5. Нормализация не үшін керек (уақыт, деңгей)?
  6. Агрегация дегеніміз не? Мысал келтіріңіз.
  7. Агент offset-ті не үшін сақтайды? Ротация дегеніміз не және агент оны қалай таниды?
  8. Көпжолды (multiline) жазбалар қалай біріктіріледі?
  9. Жинағыш қолжетімсіз болса не болады? At-least-once жеткізу дегеніміз не?
  10. Логтарда қандай деректерді сақтауға болмайды және сақтау мерзімі (retention) не үшін керек?
