1. Мәселе: сервистер бір-біріне тікелей қосылады

Микросервистер көп болған сайын олардың өзара трафигі (шығыс-батыс трафигі) күрделенеді. Әр сервистің кодында retry, timeout, шифрлау, «кімге рұқсат» және журнал жазу логикасы қайталанады. Бір сервер құласа, қате бірден пайдаланушыға жетеді, ал жаңа нұсқа барлығына бірден түседі.

Service Mesh — сервистер арасындағы байланысты кодтан бөліп, бір жерден реттейтін инфрақұрылым қабаты. API шлюзі сырттан келген трафикті басқарса, Service Mesh сервистердің өзара трафигін басқарады.

2. Құрылымы: data plane және control plane

Sidecar-прокси

Әр сервистің жанында тұратын прокси (Istio-да — Envoy). Сервис тек өз sidecar-ына сұрау жібереді.

Data plane

Барлық sidecar-лар жиыны: нақты трафик солар арқылы өтеді.

Control plane

Ережелерді сақтап, sidecar-ларға таратады (Istio: istiod). Біздің жұмыста — mesh.json және hot reload.

Мысалдар

Istio, Linkerd, Consul Connect, Cilium Service Mesh.

3. Трафикті басқару

Service discovery: sidecar қызмет атауы бойынша оның барлық данасын табады. Canary шығарылым: жаңа нұсқаға алдымен аз трафик беріледі, қате болмаса — үлес біртіндеп өседі. Тестілеушілерді тақырып бойынша бірден жаңа нұсқаға жіберуге болады.

"routing": {
  "match": [{"header": "X-User-Group", "equals": "tester", "subset": "v2"}],
  "split": {"v1": 90, "v2": 10}        # 90% — ескі, 10% — жаңа
}

4. Тұрақтылық: timeout, retry, circuit breaker

Timeout

Баяу сервисті шексіз күтпейміз: уақыт өтсе — 504.

Retry

Сәтсіз сұрауды басқа данаға қайталау. Тым көп болса — retry storm: құлап жатқан сервиске жүктеме еселенеді.

Circuit breaker

Қатарынан N қате берген дананы уақытша «ажыратып», оған сұрау жібермейміз (Istio: outlierDetection).

Ең нашар күту

timeout × (retries + 1): 800 мс × 2 = 1,6 с.

5. gRPC және HTTP трафигі

gRPC — Google жасаған RPC жүйесі: HTTP/2 үстінде жұмыс істейді, хабарламалар Protobuf (бинарлы) форматында, бір қосылымда көп ағын (multiplexing) жүреді. Шақыру — әрқашан POST /пакет.Сервис/Әдіс.

POST /aec.grades.Grades/GetGrade HTTP/2
content-type: application/grpc

Sidecar gRPC-ді жол бойынша таниды: /aec.grades.Grades/... → grades қызметі. HTTP/1.1-де әр сұрауға жеке қосылым немесе кезек керек, ал HTTP/2-де бір TCP қосылымда жүздеген параллель ағын.

6. Қауіпсіздік: mTLS және рұқсат саясаты

mTLS (mutual TLS) — екі жақ та сертификат көрсетеді. Sidecar-лар трафикті автоматты шифрлайды, ал сервистің «кім екені» IP-мен емес, сертификаттағы атаумен анықталады (cluster.local/ns/college/sa/frontend). AuthorizationPolicy кімге қай сервиске рұқсат барын жазады.

IP мекенжайы контейнер қайта іске қосылғанда өзгереді және оны жалған көрсетуге болады. Сондықтан Zero Trust желісінде сенім сертификатқа негізделеді.

# services.py — Service Mesh ішіндегі 4 оқу микросервисі
import json
import threading
import time
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

INSTANCES = [
    ("students", "v1", "students-v1-a", 9101),
    ("students", "v1", "students-v1-b", 9102),
    ("students", "v2", "students-v2-a", 9103),
    ("grades", "v1", "grades-v1-a", 9104),
]
GRADES = {1: "A", 2: "B+", 3: "C", 4: "A-"}


def make_handler(service, version, name):
    state = {"mode": "ok"}                      # ok | break | slow

    class Handler(BaseHTTPRequestHandler):
        def send(self, code, data, extra=None):
            body = json.dumps(data, ensure_ascii=False).encode("utf-8")
            self.send_response(code)
            self.send_header("Content-Type", (extra or {}).pop("ctype", "application/json; charset=utf-8"))
            self.send_header("Content-Length", str(len(body)))
            self.send_header("X-Served-By", name)
            self.send_header("X-Version", version)
            for k, v in (extra or {}).items():
                self.send_header(k, str(v))
            self.end_headers()
            self.wfile.write(body)

        def handle_any(self):
            print(name, self.command, self.path, "from:", self.headers.get("X-Mesh-Source"),
                  "rid:", self.headers.get("X-Request-ID"))
            if self.path.startswith("/admin/"):
                cmd = self.path.split("/")[2]
                state["mode"] = "ok" if cmd == "fix" else cmd
                return self.send(200, {"instance": name, "mode": state["mode"]})
            if state["mode"] == "slow":
                time.sleep(2.5)
            if state["mode"] == "break":
                return self.send(503, {"instance": name, "error": "service unavailable"})
            # gRPC стиліндегі шақыру: POST /aec.grades.Grades/GetGrade
            if self.path == "/aec.grades.Grades/GetGrade" and self.command == "POST":
                size = int(self.headers.get("Content-Length") or 0)
                req = json.loads(self.rfile.read(size) or b"{}")
                sid = req.get("student_id")
                if sid not in GRADES:
                    return self.send(200, {"message": "студент табылмады"},
                                     {"ctype": "application/grpc+json", "grpc-status": 5})
                return self.send(200, {"student_id": sid, "grade": GRADES[sid], "instance": name},
                                 {"ctype": "application/grpc+json", "grpc-status": 0})
            data = {"service": service, "version": version, "instance": name, "path": self.path}
            if service == "students" and version == "v2":
                data["new_field"] = "фото және топ"       # v2-нің жаңа мүмкіндігі
            self.send(200, data)

        do_GET = do_POST = handle_any

        def log_message(self, *args):
            pass

    return Handler


for service, version, name, port in INSTANCES:
    server = ThreadingHTTPServer(("127.0.0.1", port), make_handler(service, version, name))
    threading.Thread(target=server.serve_forever, daemon=True).start()
    print("іске қосылды: %-14s %s  http://127.0.0.1:%d" % (name, version, port))

while True:
    time.sleep(1)

def find_service(path):
    """URL-дан қызметті табу: /students/... (HTTP) немесе /aec.grades.Grades/... (gRPC)."""
    first = path.strip("/").split("/")[0]
    if first in MESH["services"]:
        return first
    for name, svc in MESH["services"].items():
        if svc.get("grpc") == first:
            return name
    return None

def pick(service, svc, subset):
    """Таңдалған нұсқаның (subset) тірі инстанстарынан кезекпен біреуін алу."""
    pool = [i for i in svc["instances"] if subset is None or i["version"] == subset]

class Sidecar(BaseHTTPRequestHandler):
    def reply(self, code, data, headers=None):
        body = data if isinstance(data, bytes) else json.dumps(data, ensure_ascii=False).encode("utf-8")
        headers = dict(headers or {})
        if self.grpc and code >= 400:                 # gRPC клиентке қате коды grpc-status-пен
            headers["grpc-status"] = GRPC_CODES.get(code, 2)
        self.send_response(code)
        self.send_header("Content-Type", headers.pop("Content-Type", "application/json; charset=utf-8"))
        self.send_header("Content-Length", str(len(body)))
        self.send_header("X-Request-ID", self.rid)
        for k, v in headers.items():
            self.send_header(k, str(v))
        self.end_headers()
        self.wfile.write(body)
        self.code = code

    def handle_any(self):
        maybe_reload()
        t0, self.code, target, tries = time.time(), 0, "-", 0
        self.rid = self.headers.get("X-Request-ID") or uuid.uuid4().hex[:12]
        self.grpc = self.headers.get("Content-Type", "").startswith("application/grpc")
        service = find_service(self.path.split("?")[0])
        try:
            if service is None:
                return self.reply(404, {"error": "mesh-те мұндай қызмет жоқ", "path": self.path})
            svc = MESH["services"][service]
            if not authorize(svc):
                return self.reply(403, {"error": "%s қызметіне %s үшін рұқсат жоқ" % (service, SOURCE)})
            subset = choose_subset(svc, self.headers)
            body = self.rfile.read(int(self.headers.get("Content-Length") or 0)) or None
            fwd = {"X-Request-ID": self.rid, "X-Mesh-Source": SOURCE}
            for h in ("Content-Type", "X-User-Group"):
                if self.headers.get(h):
                    fwd[h] = self.headers[h]
            error = 503
            for tries in range(1, svc.get("retries", 0) + 2):         # 1 әрекет + retries
                inst = pick(service, svc, subset)
                target = "%s %s" % (inst["version"], inst["addr"])
                host, port = inst["addr"].rsplit(":", 1)
                conn = http.client.HTTPConnection(host, int(port), timeout=svc["timeout_ms"] / 1000)
                try:
                    conn.request(self.command, self.path, body=body, headers=fwd)
                    resp = conn.getresponse()
                    data = resp.read()
                except (socket.timeout, TimeoutError):
                    report(inst["addr"], False)
                    error = 504
                    continue
                except OSError:
                    report(inst["addr"], False)
                    error = 503
                    continue
                finally:
                    conn.close()
                report(inst["addr"], resp.status < 500)
                if resp.status >= 500:
                    error = resp.status
                    continue
                out = {"Content-Type": resp.getheader("Content-Type"), "X-Served-By": resp.getheader("X-Served-By"),
                       "X-Version": resp.getheader("X-Version"), "X-Attempts": tries}
                if resp.getheader("grpc-status") is not None:
                    out["grpc-status"] = resp.getheader("grpc-status")
                return self.reply(resp.status, data, out)
            return self.reply(error, {"error": "қызмет жауап бермеді", "service": service}, {"X-Attempts": tries})
        finally:
            print("[%s] %d %s %s -> %s %s (%d әрекет) %d мс" % (SOURCE, self.code, self.command, self.path, service,
                                                              target, tries, (time.time() - t0) * 1000))

    do_GET = do_POST = handle_any

HEALTH = {}


def is_alive(addr):
    return HEALTH.get(addr, {}).get("open_until", 0) <= time.time()


def report(addr, ok):
    cb = MESH.get("circuit_breaker", {"consecutive_errors": 3, "eject_seconds": 15})
    h = HEALTH.setdefault(addr, {"errors": 0, "open_until": 0})
    if ok:
        h["errors"] = 0
        return
    h["errors"] += 1
    if h["errors"] >= cb["consecutive_errors"]:
        h["errors"] = 0
        h["open_until"] = time.time() + cb["eject_seconds"]
        print("[CIRCUIT] %s қатарынан %d қате -> %d секундқа ажыратылды" % (addr, cb["consecutive_errors"], cb["eject_seconds"]))

# check_mesh.py — mesh.json-ды қолданбас бұрын тексеру (CI-де іске қосылады)
import json
import re
import sys

FILE = sys.argv[1] if len(sys.argv) > 1 else "mesh.json"


def check(mesh):
    errors, warnings, addrs = [], [], set()
    for name, svc in mesh["services"].items():
        versions = set()
        for inst in svc.get("instances", []):
            if not re.fullmatch(r"[\w.-]+:\d{2,5}", inst.get("addr", "")):
                errors.append("%s: addr қате: %r" % (name, inst.get("addr")))
            if inst.get("addr") in addrs:
                errors.append("%s: %s мекенжайы қайталанады" % (name, inst["addr"]))
            addrs.add(inst.get("addr"))
            versions.add(inst.get("version"))
        if not svc.get("instances"):
            errors.append("%s: бірде-бір инстанс жоқ" % name)
        rule = svc.get("routing", {})
        split = rule.get("split", {})
        if split and sum(split.values()) != 100:
            errors.append("%s: салмақтар қосындысы %d, 100 болуы керек" % (name, sum(split.values())))
        for subset in list(split) + [m["subset"] for m in rule.get("match", [])]:
            if subset not in versions:
                errors.append("%s: '%s' нұсқасының инстансы жоқ" % (name, subset))
        t = svc.get("timeout_ms", 0)
        if not 50 <= t <= 30000:
            errors.append("%s: timeout_ms %s (50–30000 аралығында болуы керек)" % (name, t))
        if not 0 <= svc.get("retries", 0) <= 5:
            errors.append("%s: retries 0–5 аралығында болуы керек" % name)
        if "grpc" in svc and not re.fullmatch(r"[a-z]\w*(\.\w+)+", svc["grpc"]):
            errors.append("%s: gRPC атауы 'пакет.Сервис' түрінде болуы керек" % name)
        if "allow" not in svc:
            warnings.append("%s: allow жоқ — қызметке кез келген адам қосыла алады" % name)
        elif not svc["allow"]:
            warnings.append("%s: allow бос — қызметке ешкім қосыла алмайды" % name)
        if t * (svc.get("retries", 0) + 1) > 5000:
            warnings.append("%s: ең нашар жағдайда күту %d мс" % (name, t * (svc.get("retries", 0) + 1)))
    return errors, warnings


try:
    mesh = json.load(open(FILE, encoding="utf-8"))
    errors, warnings = check(mesh)
except (ValueError, KeyError) as e:
    errors, warnings = ["%s оқылмады: %s" % (FILE, e)], []
for w in warnings:
    print("  [ЕСКЕРТУ]", w)
for e in errors:
    print("  [ҚАТЕ]", e)
print("Қате саны: %d, ескерту саны: %d" % (len(errors), len(warnings)))
sys.exit(1 if errors else 0)

import json
import os

NS = "college"
mesh = json.load(open("mesh.json", encoding="utf-8"))
docs = []

docs.append("""apiVersion: security.istio.io/v1beta1
kind: PeerAuthentication
metadata:
  name: default
  namespace: %s
spec:
  mtls:
    mode: STRICT""" % NS)

for name, svc in mesh["services"].items():
    rule = svc.get("routing", {})
    t = svc["timeout_ms"] / 1000
    tries = svc.get("retries", 0)
    http = []
    for m in rule.get("match", []):
        http.append("""  - match:
    - headers:
        %s:
          exact: %s
    route:
    - destination:
        host: %s
        subset: %s""" % (m["header"].lower(), m["equals"], name, m["subset"]))
    routes = "".join("""
    - destination:
        host: %s
        subset: %s
      weight: %d""" % (name, s, w) for s, w in rule.get("split", {}).items())
    http.append("""  - route:%s
    timeout: %.1fs
    retries:
      attempts: %d
      perTryTimeout: %.1fs
      retryOn: 5xx,connect-failure,reset""" % (routes, t * (tries + 1), tries, t))
    docs.append("""apiVersion: networking.istio.io/v1beta1
kind: VirtualService
metadata:
  name: %s
  namespace: %s
spec:
  hosts:
  - %s
  http:
%s""" % (name, NS, name, "\n".join(http)))

    cb = mesh.get("circuit_breaker", {"consecutive_errors": 3, "eject_seconds": 15})
    versions = sorted({i["version"] for i in svc["instances"]})
    subsets = "".join("""
  - name: %s
    labels:
      version: %s""" % (v, v) for v in versions)
    docs.append("""apiVersion: networking.istio.io/v1beta1
kind: DestinationRule
metadata:
  name: %s
  namespace: %s
spec:
  host: %s
  trafficPolicy:
    outlierDetection:
      consecutive5xxErrors: %d
      interval: 10s
      baseEjectionTime: %ds
  subsets:%s""" % (name, NS, name, cb["consecutive_errors"], cb["eject_seconds"], subsets))

    if "allow" in svc:
        who = "".join("\n        - cluster.local/ns/%s/sa/%s" % (NS, s) for s in svc["allow"])
        docs.append("""apiVersion: security.istio.io/v1beta1
kind: AuthorizationPolicy
metadata:
  name: %s-allow
  namespace: %s
spec:
  selector:
    matchLabels:
      app: %s
  action: ALLOW
  rules:
  - from:
    - source:
        principals:%s""" % (name, NS, name, who))

os.makedirs("istio", exist_ok=True)
with open("istio/mesh.yaml", "w", encoding="utf-8") as f:
    f.write("\n---\n".join(docs) + "\n")
print("istio/mesh.yaml жасалды: %d ресурс" % len(docs))
  1. Sidecar-ды қайта іске қосыңыз. python3 check_mesh.py; echo $? → «Қате саны: 0», 0 (Windows: python check_mesh.py; echo $LASTEXITCODE).
  2. Hot reload: sidecar-ды тоқтатпай, mesh.json-да split-ті 50 / 50 етіп сақтаңыз. Келесі сұрауда 2-терминалда [RELOAD] жаңа маршруттар қолданылды; python3 client.py /students/list --n 100 → ≈ 50 / 50.
  3. Қате енгізіңіз: split 50 / 60 → check_mesh.py → «салмақтар қосындысы 110», шығу коды 1. mesh.json-ға әдейі синтаксис қатесін енгізіп сақтаңыз → sidecar «ескі конфигурация қалды» деп жұмысын жалғастырады. Файлды 90 / 10 күйіне қайтарыңыз.
  4. python3 gen_istio.py → «istio/mesh.yaml жасалды: 7 ресурс». Файлды ашып, mesh.json-дағы әр кілттің YAML-дағы орнын табыңыз (кесте: mesh.json → Istio ресурсы → өріс).
  5. Нұсқаңыз бойынша тапсырманы орындаңыз (төмендегі кесте, өз жұмысыңыз).
НұсқаТапсырма және кеңесНәтижені тексеру
1promote.py: canary қадамы — python3 promote.py students 25 mesh.json-да v2 салмағын 25-ке, v1-ді 75-ке қояды, check_mesh-тің check() функциясымен тексеріп барып сақтайды.sidecar тоқтамай 75 / 25
2Ақау енгізу (fault injection): "fault": {"delay_ms": 500, "percent": 20} — sidecar сұраулардың 20%-ын 500 мс кешіктіреді; gen_istio.py VirtualService-ке fault: delay: блогын қосады.--n 20 уақыты ≈ 2 с артады
3Трафикті айналы көшіру (mirroring): "mirror": "v2" — әр сұраудың көшірмесі v2-ге де жіберіледі (жеке ағында), жауабы ескерілмейді; gen_istio.py-ге mirror: қосу.клиент тек v1-ді көреді, v2 журналында сұраулар бар
4Sidecar статистикасы: GET /mesh/stats → қызмет, нұсқа және статус коды бойынша санауыштар (JSON).client.py --n 50-ден кейін сандар сәйкес
5Жіберушіге лимит: "rate_limit": {"per_minute": 60, "burst": 5} — token bucket (№11 жұмысы), асса 429 және grpc-status 8 (RESOURCE_EXHAUSTED).--n 20 лезде: ≈ 5 өтеді
6gen_istio.py --k8s: әр қызмет нұсқасына Kubernetes Deployment (labels: app, version) және әр қызметке Service манифесін жасайды (istio/k8s.yaml).students: 2 Deployment, 1 Service

Есепке: maybe_reload, check_mesh.py, gen_istio.py, hot reload және қателер нәтижесі, mesh.json → Istio кестесі, нұсқаңыздың коды мен нәтижесі.

Бақылау сұрақтары

  1. Service Mesh дегеніміз не және ол қандай мәселелерді шешеді?
  2. Data plane және control plane дегеніміз не? Сіздің жұмысыңызда олардың рөлін не атқарды?
  3. Sidecar-прокси дегеніміз не? Istio-да оның рөлін қай бағдарлама атқарады (Envoy)?
  4. Canary шығарылым дегеніміз не? Трафикті салмақ бойынша бөлу қалай жұмыс істейді?
  5. Retry, timeout және circuit breaker не үшін керек? Retry storm дегеніміз не?
  6. gRPC-дің HTTP/REST-тен айырмашылығы неде (HTTP/2, Protobuf, ағындар)?
  7. grpc-status кодтары: 0, 4, 5, 7, 14 нені білдіреді?
  8. mTLS дегеніміз не және Service Mesh-те қызметтің «кім екені» қалай анықталады?
  9. VirtualService, DestinationRule, AuthorizationPolicy ресурстарының әрқайсысы не үшін керек?
  10. Неге маршруттар конфигурациясын қолданбас бұрын автоматты түрде тексерген дұрыс?
