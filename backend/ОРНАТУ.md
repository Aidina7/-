# Как подключить приём работ и админку (один раз, ~10 минут)

Сайт работает на GitHub Pages, а данные (сданные работы, оценки, результаты тестов) хранятся
в **вашей Google Таблице**, файлы студентов — в **вашем Google Диске**. Посредник — Google Apps Script.

## Шаг 1. Таблица и скрипт
1. Откройте https://sheets.new — создастся новая Google Таблица. Назовите её «Оқу практикасы — жұмыстар».
2. Меню **Расширения → Apps Script**.
3. Удалите всё в файле `Code.gs` и вставьте содержимое файла `backend/Code.gs` из этого репозитория.
4. В самом начале файла замените `ӨЗГЕРТІҢІЗ-2026` на свой пароль для админки (минимум 8 символов). Нажмите 💾.

## Шаг 2. Первый запуск
1. Вверху выберите функцию **setup** и нажмите **▶ Выполнить**.
2. Google попросит разрешения → **Проверить разрешения** → выберите свой аккаунт →
   «Дополнительные настройки» → «Перейти на страницу…» → **Разрешить**.
   (Скрипт работает только с этой таблицей и создаёт одну папку на Диске.)
3. В таблице появятся листы «Тапсырылған жұмыстар» и «Тест нәтижелері», на Диске — папка
   «Оқу практикасы — студенттер жұмыстары».

## Шаг 3. Публикация
1. **Развернуть → Новое развертывание** → тип ⚙️ **Веб-приложение**.
2. Выполнять как: **Я**. У кого есть доступ: **Все**.
3. **Развернуть** → скопируйте **URL веб-приложения** (заканчивается на `/exec`).

## Шаг 4. Сайт
Отправьте этот URL Claude — он впишет его в `assets/config.js` (поле `API_URL`) и опубликует сайт.
Или сами: на GitHub откройте `assets/config.js` → ✏️ → вставьте URL в кавычки `API_URL: "..."` → Commit.

## Как пользоваться
- Админка: ссылка «Оқытушыға кіру» внизу сайта (`admin.html`) → ваш пароль.
- Оценка и комментарий, которые вы сохраняете, студент видит по своему коду на странице «Бағамды тексеру».
- Все данные видны и в самой Google Таблице; файлы — в папке на Google Диске.

## Если что-то поменяли в Code.gs
**Развернуть → Управление развертываниями → ✏️ → Версия: Новая → Развернуть.** URL не меняется.

## Сменить пароль
Измените `ADMIN_PASSWORD` в начале `Code.gs` и снова запустите **setup**.
