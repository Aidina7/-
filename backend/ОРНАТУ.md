# Сервер (Google Apps Script) — 2-нұсқа

Сайт GitHub Pages-те, деректер Google Таблицада («Оқу практикасы — жұмыстар»), файлдар Google Диске.

Таблица парақтары: **Студенттер**, **Тапсырылған жұмыстар**, **Тест нәтижелері**, **Ойындар**.

## Кодты жаңарту
1. Жабық репозиторийде: `python site-secrets/mkdeploy.py /tmp/Code.deploy.gs <оқытушы құпиясөзі>` — тест жауаптары мен құпиясөз қосылған толық код.
2. Apps Script редакторында Code.gs мазмұнын ауыстырып, сақтау.
3. `setup` функциясын бір рет іске қосу (жаңа парақтар мен токен кілтін жасайды).
4. **Deploy → Manage deployments → ✏️ → Version: New version → Deploy.** URL өзгермейді.

## Маңызды
- Бұл ашық файлда дұрыс жауаптар мен құпиясөз **жоқ** — олар тек Apps Script ішінде.
- Студенттің құпиясөзін оқытушы панелінен қалпына келтіруге болады (студент → «құпиясөзді қалпына келтіру»).
