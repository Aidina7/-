1. API шлюзі деген не?

Колледжде бірнеше қызмет бар: студенттер, бағалар, кесте. Шлюзсіз әр клиент (мобильді қосымша, бот, сайт) әр қызметтің мекенжайын біледі, ал кілтті, лимитті, журналды әр қызмет өзі тексереді. Бір қызмет ұмытса — тесік пайда болады.

API шлюзі (API Gateway) — клиенттер мен қызметтердің арасындағы бір кіру нүктесі. Барлық сұрау алдымен шлюзге келеді, ол ортақ ережелерді бір жерде тексеріп, сұрауды керек қызметке жібереді.

Маршруттау

URL басы бойынша қай қызметке жіберу керегін табады: /api/students → students.

Аутентификация

X-API-Key тақырыбын тексереді. Кілт жоқ — 401.

Лимит

Клиентке минутына N сұрау. Асса — 429 Too Many Requests.

Жүктемені бөлу

Бір қызметтің бірнеше данасы болса, сұрауларды кезекпен таратады.

Сенімділік

Timeout, қайталау, ақаулы серверді уақытша тізімнен шығару.

Журнал

Әр сұрау бір жолда: кім, қайда, қандай код, қанша мс. X-Request-ID арқылы бақылау.

Нақты шлюздер: NGINX, Kong, Traefik, Envoy, бұлтта — AWS API Gateway, Azure API Management. Практикалық жұмыста сіз олардың шағын үлгісін — gateway.py шлюзін таза Python-да өзіңіз жазасыз.

3. Маршруттау

Шлюз сұрау жолын барлық prefix-термен салыстырады. Бірнеше prefix сәйкес келсе — ең ұзыны жеңеді. Сосын prefix қызметтегі жолға ауыстырылады:

/api/students/3?full=1   →   http://127.0.0.1:9001/students/3?full=1
/api/schedule?day=mon    →   http://127.0.0.1:9004/schedule?day=mon
/api/teachers            →   404 «маршрут табылмады» (жауапты ШЛЮЗ берді)
КодКім қайтарадыСебебі
401шлюзX-API-Key жоқ немесе қате
404шлюз немесе қызметмаршрут жоқ / ресурс жоқ (X-Upstream тақырыбы бар ма — соған қараңыз)

Шлюз әр сұрауға X-Request-ID береді және оны қызметке де жібереді. Қате болса, осы ID арқылы сұрауды шлюз журналынан да, қызмет журналынан да табасыз (tracing).

4. Лимит: token bucket алгоритмі

Әр клиентке бір «шелек» беріледі. Шелекке секундына per_minute / 60 жетон құйылады, шелектің сыйымдылығы — burst. Әр сұрау бір жетон алады. Жетон жоқ болса — 429.

def take(self):
    now = time.monotonic()
    self.tokens = min(self.capacity, self.tokens + (now - self.last) * self.rate)
    self.last = now
    if self.tokens >= 1:
        self.tokens -= 1
        return True          # өтеді
    return False             # 429

Нәтижені алдын ала есептеуге болады: рұқсат ≈ burst + (per_minute / 60) × T, мұнда T — жүктеме ұзақтығы (секунд).

Мысал: per_minute = 60, burst = 10. Клиент 20 секунд бойы секундына 2 сұрау жібереді (барлығы 40). Өтеді ≈ 10 + 1 × 20 = 30, ал 10 сұрау 429 алады.

Кілтсіз маршрутта лимит IP бойынша қойылады. Бір сыныптағы барлық компьютер бір сыртқы IP-ден шықса, олар бір шелекті бөліседі — сондықтан кілт бойынша лимит әділірек.

5. Жүктемені бөлу және сенімділік

Round robin

Сұраулар кезекпен: 9001, 9002, 9001, 9002 ... Әр сервер жүктеменің жартысын алады.

Passive health check

Сервер қатарынан 2 рет жауап бермесе, шлюз оны 15 секундқа тізімнен шығарады.

Retry

GET сұрауын басқа серверге қайталау қауіпсіз. POST-ты қайталау — студентті екі рет қосу қаупі.

Timeout

Баяу қызметті шексіз күтпейміз: timeout_ms өтсе — 504.

# backends.py — шлюздің артындағы 4 оқу қызметі
import json
import threading
import time
from http.server import BaseHTTPRequestHandler, ThreadingHTTPServer

INSTANCES = [("students-1", 9001), ("students-2", 9002), ("grades-1", 9003), ("schedule-1", 9004)]


def make_handler(name):
    state = {"mode": "ok"}                      # ok | break | slow

    class Handler(BaseHTTPRequestHandler):
        def send_json(self, code, data):
            body = json.dumps(data, ensure_ascii=False).encode("utf-8")
            self.send_response(code)
            self.send_header("Content-Type", "application/json; charset=utf-8")
            self.send_header("Content-Length", str(len(body)))
            self.send_header("X-Served-By", name)
            self.end_headers()
            self.wfile.write(body)

        def do_GET(self):
            print(name, self.command, self.path, "request-id:", self.headers.get("X-Request-ID"))
            if self.path.startswith("/admin/"):
                cmd = self.path.split("/")[2]
                state["mode"] = "ok" if cmd == "fix" else cmd
                return self.send_json(200, {"instance": name, "mode": state["mode"]})
            if state["mode"] == "slow":
                time.sleep(2.5)
            if state["mode"] == "break":
                return self.send_json(503, {"instance": name, "error": "service unavailable"})
            self.send_json(200, {"instance": name, "path": self.path})

        do_POST = do_GET

        def log_message(self, *args):
            pass

    return Handler


for name, port in INSTANCES:
    server = ThreadingHTTPServer(("127.0.0.1", port), make_handler(name))
    threading.Thread(target=server.serve_forever, daemon=True).start()
    print("іске қосылды:", name, "http://127.0.0.1:%d" % port)

while True:
    time.sleep(1)

    global CFG
    with open(CONFIG_FILE, encoding="utf-8") as f:
        CFG = json.load(f)
    print("конфигурация жүктелді, маршрут саны:", len(CFG["routes"]))


def match(path):
    """Ең ұзын сәйкестік: ұзын prefix бірінші тексеріледі."""

class Gateway(BaseHTTPRequestHandler):
    def reply(self, code, data, headers=None, ctype="application/json; charset=utf-8"):
        body = data if isinstance(data, bytes) else json.dumps(data, ensure_ascii=False).encode("utf-8")

        self.send_header("Content-Type", ctype)
        self.send_header("Content-Length", str(len(body)))

        for k, v in (headers or {}).items():
            self.send_header(k, str(v))
        self.end_headers()
        self.wfile.write(body)

        self.code, client, target, t0 = 0, "-", "-", time.time()
        maybe_reload()
        path = urlsplit(self.path).path

class TokenBucket:
    def __init__(self, per_minute, burst):
        self.rate = per_minute / 60          # секундына қанша жетон құйылады
        self.capacity = burst                # шелектің сыйымдылығы
        self.tokens = burst
        self.last = time.monotonic()

    def take(self):
        now = time.monotonic()
        self.tokens = min(self.capacity, self.tokens + (now - self.last) * self.rate)
        self.last = now
        if self.tokens >= 1:
            self.tokens -= 1
            return True, int(self.tokens), 0
        retry = int((1 - self.tokens) / self.rate) + 1
        return False, 0, retry


BUCKETS = {}


def check_key(handler, route):
    """(клиент, тариф) қайтарады; кілт қате болса None."""
    if route.get("auth", "none") == "none":
        return "ip:" + handler.client_address[0], "basic"
    key = handler.headers.get("X-API-Key", "")
    for c in CFG.get("consumers", []):
        if c["key"] == key:
            return c["name"], c["plan"]
    return None


def check_limit(route, client, plan):
    k = CFG.get("plans", {}).get(plan, 1)
    rl = route["rate_limit"]
    name = (route["name"], client)
    if name not in BUCKETS:
        BUCKETS[name] = TokenBucket(rl["per_minute"] * k, rl["burst"] * k)
    return BUCKETS[name].take()

RR = {}
HEALTH = {}
MAX_FAILS, FAIL_TIMEOUT = 2, 15


def pick_targets(route):
    t = route["targets"]
    counter = RR.setdefault(route["name"], itertools.count())
    start = next(counter)
    ordered = [t[(start + i) % len(t)] for i in range(len(t))]
    alive = [x for x in ordered if HEALTH.get(x, {}).get("down_until", 0) <= time.time()]
    return alive or ordered


def mark(target, ok):
    h = HEALTH.setdefault(target, {"fails": 0, "down_until": 0})
    if ok:
        h["fails"] = 0
        return
    h["fails"] += 1
    if h["fails"] >= MAX_FAILS:
        h["fails"] = 0
        h["down_until"] = time.time() + FAIL_TIMEOUT
        print("[HEALTH]", target, "жауап бермеді ->", FAIL_TIMEOUT, "секундқа тізімнен шығарылды")

# validate_config.py — шлюз конфигурациясын тексеру
import json
import sys

METHODS = {"GET", "POST", "PUT", "PATCH", "DELETE"}


def validate(cfg):
    errors, warnings = [], []
    names, prefixes = set(), set()
    for r in cfg["routes"]:
        n = r["name"]
        if n in names:
            errors.append("%s: атау қайталанады" % n)
        names.add(n)
        if not r["prefix"].startswith("/"):
            errors.append("%s: prefix / белгісінен басталуы керек" % n)
        if r["prefix"] in prefixes:
            errors.append("%s: prefix қайталанады" % n)
        prefixes.add(r["prefix"])
        for m in r["methods"]:
            if m not in METHODS:
                errors.append("%s: белгісіз әдіс %s" % (n, m))
        for t in r["targets"]:
            host, _, port = t.rpartition(":")
            if not host or not port.isdigit() or not 1 <= int(port) <= 65535:
                errors.append("%s: target дұрыс емес: %s" % (n, t))
        if r.get("auth", "none") not in ("none", "key"):
            errors.append("%s: auth тек none немесе key" % n)
        if r["rate_limit"]["burst"] > r["rate_limit"]["per_minute"]:
            warnings.append("%s: burst минуттық лимиттен үлкен" % n)
    for c in cfg.get("consumers", []):
        if len(c["key"]) < 16:
            errors.append("клиент %s: кілт тым қысқа (кемінде 16 таңба)" % c["name"])
    return errors, warnings


if __name__ == "__main__":
    path = sys.argv[1] if len(sys.argv) > 1 else "gateway.json"
    with open(path, encoding="utf-8") as f:
        cfg = json.load(f)
    errors, warnings = validate(cfg)
    for e in errors:
        print("[ҚАТЕ]", e)
    for w in warnings:
        print("[ЕСКЕРТУ]", w)
    print("Нәтиже:", "ҚОЛДАНУҒА БОЛМАЙДЫ" if errors else "OK")
    sys.exit(1 if errors else 0)

6-тапсырма. Журнал және жеке нұсқа (30 мин, 15 ұпай)

Алдымен барлығына ортақ: gateway.py-де write_log заглушкасын төмендегі кодпен ауыстырыңыз, шлюзді қайта іске қосып, бірнеше сұрау жіберіңіз → logs/access.log файлында әр сұрау бір JSON жол. Содан кейін нұсқаңыздағы мүмкіндікті өзіңіз қосасыз (бұл бөлім — өз жұмысыңыз, кеңес берілген).

Файл: gateway.py — write_log орнына

def write_log(rec):
    os.makedirs("logs", exist_ok=True)
    with open("logs/access.log", "a", encoding="utf-8") as f:
        f.write(json.dumps(rec, ensure_ascii=False) + "\n")

Бақылау сұрақтары

  1. API шлюзі дегеніміз не? Ол қандай міндеттерді атқарады?
  2. Сіздің match() функцияңыз маршрутты қалай табады? «Ең ұзын сәйкестік» не үшін керек?
  3. 401, 404, 405, 429, 502, 504 кодтарын сіздің шлюзіңіз қай жағдайда қайтарады?
  4. TokenBucket қалай жұмыс істейді? per_minute мен burst айырмашылығы неде?
  5. Лимитті IP бойынша және API кілті бойынша қоюдың айырмашылығы қандай?
  6. pick_targets() және mark() қалай жұмыс істейді?
  7. Неге GET-ті басқа серверге қайталауға болады, ал POST-ты әрдайым қайталауға болмайды?
  8. Hot reload кезінде жаңа конфигурацияда қате болса, шлюз не істейді?
  9. gateway.json-ды кестеден генерациялап, валидатормен тексерудің пайдасы қандай?
  10. Сіздің шлюзіңіздің бөліктері NGINX-те қалай аталады?
