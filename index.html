Оқу практикасы: ақпараттық жүйелерді автоматтандыру

ИС 3-1 тобына арналған материалдар. Әр практикалық жұмыста теория, бейне, Python-дағы бастапқы код, нұсқалы тапсырмалар, тест және жұмысты тапсыру формасы бар.

Хабарландырулар

  • 19.11.2026 №9 «Желілік аномалиялар» және №10 «SLA» тақырыптары қосылды. Әр тақырыпта бейнетүсіндірме бар.
  • 18.11.2026 Сайтқа тіркелу ашық. Тест нәтижелері, жұмыстар мен бағалар кабинетте сақталады.
  • 18.11.2026 Тест: 16 сұрақтың ішінен кездейсоқ 10 сұрақ, 3 әрекет. Ең жақсы нәтиже есептеледі.

Қалай жұмыс істеу керек

  1. Тіркеліңіз. Логинді латынша жазыңыз, аты-жөніңізді журналдағыдай көрсетіңіз.
  2. Тақырыпты ашып, алдымен «Теория» бөлімін оқыңыз, содан кейін бейнені қараңыз.
  3. «Файлдар» бөлімінен бастапқы кодты жүктеп, өз нұсқаңызды орындаңыз.
  4. Тест тапсырыңыз. 3 әрекет бар, ең жақсы нәтиже есептеледі.
  5. Есепті «Жұмысты тапсыру» формасы арқылы жіберіңіз. Баға кабинетте шығады.

Бағалау

  • Практикалық жұмыс: 100 баллдық шкала, критерийлері әр тапсырманың соңында.
  • Тест: 10 сұрақ, ең жақсы әрекет есептеледі.
  • Ойындар мен челлендждер: қосымша ұпай, топ рейтингіне шығады.

Қажетті бағдарламалар

  • Python 3.10 немесе жоғары (орнатқанда Add Python to PATH белгісін қойыңыз)
  • Visual Studio Code және Python кеңейтімі

Тексеру үшін терминалда: python --version (Mac-та python3 --version).
